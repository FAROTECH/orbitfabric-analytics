# Community participation baseline: 2026-08-17 to 2026-09-06

## Purpose

This review records the first M3e repository-scoped participation baseline across the six official OrbitFabric repositories.

Participation is derived from actor-bearing GitHub surfaces currently covered by M3e:

- issue authors;
- pull-request authors;
- issue / pull-request conversation comments.

The analysis is repository-scoped. `first_seen` means the earliest reconstructed observation since the configured observation baseline for a login in one repository. It does not mean a new GitHub user, a first ecosystem-wide appearance, or an external contributor.

## Result

The initial retained window contains only one observed participant identity across all six official repositories: `FAROTECH`, classified by policy as `first_party`.

Consequently:

```text
other_participants_repo_count = 0
automation_participants_repo_count = 0
other_participants_first_seen_repo_count = 0
```

throughout the retained participation window.

This is consistent with the current development phase. OrbitFabric has public traffic and public upstream/community activity, but the official GitHub repositories do not yet show repository-local participation from a second observed actor on the M3e surfaces.

## Public-retention note

The first implementation temporarily retained a cumulative actor registry while M3e semantics were being validated. Before OrbitFabric Analytics was prepared for public repository visibility, that registry was removed and the collector was redesigned to reconstruct first-observed state from public GitHub events since `2026-08-17`.

The removed registry contained only the maintainer login `FAROTECH`. No third-party participant identity had been retained.

The public analytics history now retains aggregate repository-day participation counts only.

## Activity shape

The absence of additional participant identities does not mean an absence of GitHub activity.

Examples:

- 2026-08-26 Core records 7 issue-author events, 6 pull-request-author events and 24 comment events, all associated with one first-party participant.
- 2026-09-03 F Prime records 7 pull-request-author events, OpenC3 / COSMOS records 6, and OpenOBSW / OpenSVF records 8, again with one first-party participant per active repository.

This distinction is important: M3c and M3d already showed high engineering and lifecycle volume; M3e confirms that the observed actor-bearing activity in this window is still first-party rather than evidence of a broader GitHub participant set.

## Interpretation boundary

The correct conclusion is:

> No `other` repository-scoped participant has yet been observed on the currently collected M3e GitHub surfaces during the retained baseline window.

The data does not support stronger claims such as:

- nobody external has viewed, cloned or used OrbitFabric;
- nobody external has interacted with OrbitFabric outside these GitHub surfaces;
- the project has no external audience;
- future `other` actors are necessarily external contributors.

Traffic, upstream discussions, Libre Space contributions and repository participation remain separate evidence families.

## Next implication

This baseline establishes a clean T0 for repository participation. Future non-zero `other_participants_repo_count` or `other_participants_first_seen_repo_count` values will be detectable while keeping nominative actor identity out of retained public analytics state.
